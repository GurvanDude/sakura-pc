# Sakura Light : feuille de route

Éclairage RGB du PC synchronisé avec le launcher : noir à l'allumage, tempête de sakura, ambiances
jour / nuit, animation « C'est parti ». Appli de réglage : Sakura Lumières.

- [x] Carte mère GIGABYTE (prises ARGB) et RAM Corsair via OpenRGB (pilote PawnIO), sans iCUE.
- [x] Tempête au démarrage synchronisée avec l'écran, ambiances jour / nuit, « C'est parti » jour / nuit.
- [x] Noir à l'allumage (BIOS : « LEDs in System Power On State » sur Off) et à l'extinction (reset direct de la puce).
- [x] Appli Sakura Lumières : test par zone, galerie d'effets, réglages enregistrés.
- [ ] Installation guidée (OpenRGB, PawnIO, tâche planifiée) pour un autre PC.
- [ ] Logo et icône de la DA commune.

Matériel testé : B550 AORUS ELITE AX V2, Corsair Vengeance RGB Pro DDR4.
