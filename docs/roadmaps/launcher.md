# Sakura Launcher : feuille de route

Écran de démarrage qui remplace le bureau Windows : on choisit un jeu (écran principal) et les applis
d'à côté (écran secondaire), puis « C'est parti ».

- [x] Deux écrans, jeux et applis, ordre des applis respecté, fond animé jour / nuit.
- [x] Mode coquille Windows (le launcher s'affiche avant le bureau), tri des applis au démarrage.
- [x] Sons coupés pendant le lancement, Spotify mis en pause, fond d'écran animé attendu.
- [x] Bibliothèque Steam / Epic synchronisée, jaquettes téléchargées.
- [x] Modes « musique » (FL Studio) et « lancement classique ».
- [ ] Passer le launcher installé sur le dépôt (dossier utilisateur %APPDATA%\SakuraPC).
- [ ] Interface pour ajouter / retirer des jeux et applis sans toucher au fichier de config.
- [ ] Logo et icône de la DA commune.
